# 🛡️ SentinelAI – AI Cybersecurity Copilot

An AI-powered Security Operations Center (SOC) assistant built using Generative AI, Multi-Agent Systems, RAG Architecture, and Cybersecurity Threat Intelligence.

---

# 🚀 Features

- 🔍 AI Threat Analysis
- 🤖 Multi-Agent Security System
- 🧠 CVE Intelligence Assistant
- 📄 PDF Incident Report Export
- 📚 Security RAG Chatbot
- 📊 Real-Time SOC Dashboard
- 🚨 Suspicious IP Detection
- 🛡️ Mitigation Recommendation System

---

# 🧠 AI Technologies Used

- NVIDIA API
- Llama 3.1 70B
- LangChain
- ChromaDB
- RAG (Retrieval-Augmented Generation)
- Multi-Agent AI Architecture
